# RPG: Hero's Journey

A simple JavaScript-based text RPG game where you play as a hero fighting monsters, collecting gold, gaining XP, and leveling up through battles.

## Features
- Turn-based combat with various monsters  
- Inventory and weapon upgrades  
- Health and gold management  
- Easter egg mini-game  
- Background music with toggle control  

## How to Play
1. Open `index.html` in a browser.  
2. Use the buttons to explore, fight, and manage your stats.  
3. Toggle the background music using the "Music On/Off" button.

## Notes
- The audio file (`bgm.m4a`) is not included in this repository due to size.  
  Please download it separately and place it in the project folder.

## Files
- `index.html` – Main HTML structure  
- `style.css` – Styling for the game interface  
- `script.js` – Game logic and functionality
